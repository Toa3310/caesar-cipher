# シーザー暗号ツール

## 概要
シーザー暗号の暗号化・復号化をPythonで行うツール

## 作ろうと思った理由

- 授業で学んだ内容をもとに、実際に自分でプログラムを作成することで理解を深めたかったから
- 単にコードを書くことにとどまらず、GitHubでの公開やREADMEの作成まで含めて行うことで、小規模ながら実際の開発に近い一連の流れを自分主体で体験したかったから
- 将来セキュリティ系にぼんやりなりたいと考えており、そのために暗号ついての理解を深めたかったから

## 特徴および工夫した点
- 暗号化・復号化処理、文字の変換、モード適用(暗号化・復号化)を別の関数に分けることで、処理の確認をしやすくし、コードを見やすくした
- 入力された文字を1文字ずつ処理することで、シンプルな構造で実装した
- 暗号化か復号化かでシフト数をそのまま渡すか負の値で渡すかを決め、内容が重複しないようにした
- シフト数を入力しないまま暗号化・復号化したときの例外処理を追加した

## 使い方
> [!WARNING]
テキスト入力欄にアルファベット以外を入力すると、正しい暗号化・復号がされません!

### CLI版
以下のコマンドを実行する<br>
```
python main.py
```
実行後、平文とシフト数を入力することで暗号化および復号ができます

### Web版
以下のコマンドを実行する<br>
```
python app.py
```
その後、ブラウザで以下にアクセス<br>
http://127.0.0.1.5000<br>
文とシフト数を入力し、モードを選択することで結果が表示されます

## Web版について
CLI版が完成後、Web上で動作するようにしたいと考え、Flaskを用いてCLI版と同じ処理ができるようにしました
